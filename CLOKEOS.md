# ClokeOS changes

This branch holds the changes [ClokeOS](https://github.com/cloke-tech/ClokeOS) makes on top of Darling (darling-corefoundation) (base: `the default branch at the time`).
It is a fork used by ClokeOS; thank you to the original authors. The changes follow the licence of the upstream project.
Patch files and the build scripts that apply them live in ClokeOS under `clokeos-darwin/macapps/`.
ClokeOS builds Darling's Mac frameworks on PureDarwin's objc4 and dyld. Its fix-ups are small patch/sed files under `macapps/patches/` in ClokeOS.
